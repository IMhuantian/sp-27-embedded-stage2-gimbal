# Pitch 双环第一版（2026-10-22）

用户同意将Pitch改为双环。当前本地主工程的手动保持与轨迹模式均改为角度P外环＋电机速度PI内环；Yaw保留原串级，折叠轴保留原位置PID。本轮没有烧录、复位或驱动硬件，以下增益只是未整定的台架初值，不是稳定性结论。

## 控制路径与单位

`角度误差 × position_kp + 轨迹速度前馈 -> ±5.5 rad/s限制 -> 减去实际速度 -> 速度PI -> ±0.3 Nm限制 -> 3 Nm/s输出变化率限制 -> M2006 cmd`

- 位置反馈仍为`PITCH_FB_SIGN × IMU.pitch`，即抬头为正。
- 内环速度读取`PITCH_RATE_FB_SIGN × pitch_motor.speed`。中间件已按36:1换算为减速输出侧rad/s，不再除36、不直接使用电机轴rpm；若机构还有额外传动比，现有配置仍需据实修正。
- 输出为减速输出侧Nm，最终乘`PITCH_OUT_SIGN`。当前位置符号−1、速度符号+1、输出符号+1。速度符号+1是与原电机方向约定一致的假设，本次尚未实测它与IMU“抬头为正”的对应关系。速度符号与IMU角度符号不是同一件事，不能直接复制−1。
- 原30ms角度超前设为0；未经辨识的0.004加速度转矩前馈从控制路径移除。改用轨迹自身的速度前馈，避免同时改变角参考与再加速度前馈导致整定含混。评分继续比较未修改的原角参考。
- 轨迹幅值仍0.5、周期仍680ms，Pitch无旧超前时目标峰速约4.154rad/s。仍用5.5rad/s目标变化率限制；若角给定被变化率/可选范围限制，前馈取实际受限目标的变化率，不能继续用超界的原轨迹速度。
- 手动仍是左摇杆上下积分成角目标，松手保持该目标。前馈为这次实际目标增量/dt；手动速度上限仍0.8rad/s。

| 速度内环I | 0.3 | Nm/rad，试验初值，需低速台架整定 |
| 目标速度上限 | 5.5 | rad/s，保留当前试验限速 |
| 转矩上限 | 0.3 | 减速输出侧Nm，未提高 |
| 输出变化率 | 3.0 | Nm/s，未提高 |

新外P×内P的小信号等效位置刚度为0.9Nm/rad，低于旧单环P的3Nm/rad；这只是静态线性项比较，不能预测真实带宽或证明更稳。电机负载、重力、摩擦和内部驱动动态尚未辨识。若所需保持转矩大于0.3Nm，换成双环也不能凭算法解决转矩不足。

## 状态、时序与保护

- PI积分针对最终转矩夹紧和输出变化率两处做条件积分：误差仍会推动输出进一步进入受限方向时，不累积该次积分；有利于退出饱和时允许积分。
- 每次使能的Pitch目标仍就地接管。进入轨迹清积分，并从当前已输出转矩接续变化率限制；失能清积分和输出状态，立即零指令。轨迹退出到手动保持延续角目标。
- Pitch积分与手动目标/参考变化率使用本周期实际经过的毫秒数。相同tick的重复调度不重复积分；超过20ms置新故障9并停机。评分仍要求1ms，发生漏拍继续标记本轮评分时序无效。
- 非有限输入/非法配置也触发故障9。下档清锁、遥控/反馈超时、折叠展开、Yaw边界、原姿态保护均保留。Pitch角范围开关仍按用户前次要求关闭。
- **故障5仍是姿态/跟随保护**，含“Pitch误差大于20°且输出大于0.2Nm持续50拍”。它不属于已取消的角度范围，改双环不意味着保证不再触发。
- CAN发送返回值处理和更严格的接收帧校验没有在本次改动，不把软件转矩指令当作实际收到的转矩。

## SerialPlot 18通道更新

帧头AA BB、size 0x48、18个float32、小端、921600不变。

- 界面第8通道（wire7）：改为**俯仰目标角速度（弧度/秒）**，不再是PID目标角；显示增益改为1。
- 第9通道（wire8）：速度符号换算后的输出侧实际速度rad/s，与上一通道同一正方向。
- 第10通道（wire9）：送驱动的Pitch转矩Nm。
- 第14通道（wire13）：新速度PI限幅前P+I需求Nm，不再是旧位置PID加加速度前馈。
- “限幅状态”（wire10）新增32=Pitch外环目标速度受限；8仍包含任一轴转矩限幅，16仍包含输出变化率限制。
- “故障代码”（wire11）新增9=控制间隔过长或Pitch控制输入/配置无效。评分通道14～17（wire）及其公式不变。

四套config/gimbal-*-18ch.ini已同步中文标签和增益，控制量页现在同时显示Pitch目标/实际速度。重新加载配置后再记录；本轮未操作SerialPlot窗口或打开串口。

## 台架步骤与验证范围

1. 用户人工支撑机构、右拨杆下档，先核对烧录版本、M2006角色/减速比及编码速度和IMU方向；本轮不自动烧录。当前Pitch无角度范围夹紧，必须先人工核实行程和线束余量。
2. 首先隔离整定速度环：可将`pitch_config`中的position_kp临时设0，先用中档手动低速短动作比较wire7/8，确认速度反馈为负反馈，再调整内环P，随后小幅增加I；该模式不保证松杆位置保持，须有机械支撑。
3. 恢复角外环后先静态保持、小角度低速跟踪，再试当前0.5轨迹。采集wire5/6角度、7/8速度、9/13输出、10/11限制与故障、14～17评分。重点区分错向、速度滞后、持续饱和、负载不足和保护首发事件。出现异常先停下定位，不继续取消其他保护。
4. 增益没有实机整定、没有0.5或1.0实际评分；不能因编译/理想输入测试通过宣称稳定。正式轨迹幅值/时间与机械可达性仍需独立验收。

新增`tests/run_pitch_tests.ps1`覆盖真实控制接口的角度外环/速度前馈/反馈阻尼、独立限速限矩、转矩与输出变化率抗饱和、实际dt积分、停机/重使能/输出接续、非有限/非法参数/超时。原轨迹与评分回归也通过。测试不模拟电机实体、CAN/RTOS中断、重力负载或机械干涉。
