## 如何评分

- 每个有效1ms样本调用yaw_detect和pitch_detect。`ratio = 0.001 × 命中 + 0.999 × 上次ratio`。ratio是0～1，不是百分数。
- 本轮平均分 = `(mean(yaw_ratio)×0.5 + mean(pitch_ratio)×0.5)×40`，即0～40分。平均对象是每拍的滤波ratio，不是末值，也不是直接命中率。比如连续完美跟踪的首拍ratio=0.001，首拍分数只有0.04分；滤波从零启动会带来预热效应。
- 截图没有指定正式取平均的时长/滤波预热方式。本地统计从每次有效进入轨迹开始、到停止或故障，包含预热；只表示本轮平均，不冒充裁判指定窗口。比较固件时应使用相同初始姿态、负载和测试时长。
- 比较的是0.5倍的原参考，不能拿加30ms超前/截断/变化率限制后的Pitch设定去评分。Pitch实际直接用IMU pitch，目标由“仰为正”的轨迹参考除以PITCH_FB_SIGN转换成同一IMU约定。Yaw保持官方直接相减，未给评分函数加wrap；控制环自身的wrap处理不等于评分函数也wrap。跨±pi时应记录该情况供组委会确认。
- 当前幅值0.5，状态始终带调试标志。即使显示很高的分数，也不是正式1.0轨迹成绩。原1.0范围冲突仍未解决。截图明确禁止折叠机构辅助Pitch轨迹，否则Pitch系数为0；本程序保持原折叠展开目标，不主动用折叠追Pitch，但机械合规与实际是否参与运动仍需人工核实，软件不自动裁定此项。

## 生命周期与任务周期

- 上电为无样本，不显示成有效0分；实际进入有效轨迹才清零并开始统计。中档手动、预览、dry-run、轨迹入口被拒绝，不累积成绩。
- 退出后冻结本轮ratio/均值/样本数；下一次进入重新开始。故障中断标记Aborted；不得把很短的故障前片段当作完整成功测试。重启/烧录不保留RAM成绩，先保存CSV/JSON再换固件。
- 云台任务改为`vTaskDelayUntil(...,1ms)`绝对周期等待，各退出分支一致。真实采样时间差不是1ms会锁存TimingInvalid；同一tick重复运行不重复计分，不虚构补采。反馈不健康/非有限也会标记。正常退出本轮仍保留，异常恢复不清除该轮标记。
- 固定周期调用不保证实际无抖动。SPI/中断/调度与栈余量仍待实机验证。IMU快照就绪不是SPI健康认证。

## SerialPlot：现在必须改为18通道

保留原0～13大部分诊断含义，新增14～17。帧为`AA BB + size=0x48 + 18×float32 little-endian`，共75字节；921600 8N1，无校验。不能继续按14通道/0x38解释。18通道使用中间件现有接口，没有修改中间件。

| 通道 | 含义 |
|---|---|
| 0/1 | Yaw参考/实际rad |
| 2/3 | Yaw目标/电机速度rad/s |
| 4 | Yaw最终转矩Nm |
| 5/6 | Pitch原参考/仰为正实际rad |
| 7 | Pitch超前及限制后的控制设定rad，不用于评分 |
| 8/9 | Pitch电机输出侧rad/s、最终Nm |
| 10/11 | 限制标记、云台故障，见HALF_TRIAL文档 |
| 12 | **本轮评分有效样本数**，覆盖旧“试验已过ms”，停止后保留 |
| 13 | Pitch限前P+I+D+加速度前馈Nm |
| 14 | 当前yaw_ratio |
| 15 | 当前pitch_ratio |
| 16 | 本轮ratio平均分，0～40；尚无样本时数值0但不构成有效分数 |
| 17 | 评分状态位，相加见下 |

状态位：1=正在统计，2=已有有效样本，4=周期异常，8=反馈异常，16=非1.0幅值调试，32=故障中断。典型0.5正常运行19=1+2+16；正常停止18=2+16。含4/8/32的结果不可按完整有效测试解释。即使无异常位，也须满足正式轨迹、窗口和机械合规。

## 每次烧录后取得结果

本次没有烧录。后续用户烧录并人工完成台架测试后，可选：

1. SerialPlot查看/保存上述18通道CSV，提供给本会话。停止后通道16保留该轮平均分。
2. 关闭SerialPlot以释放串口，运行只读工具：`python tools/capture_trajectory_score.py --port COM5 --seconds 15`。COM5只是示例，必须替换实际串口。工具需要pyserial，不发送串口命令、不触发电机；在人工上档前开始采集、下档后结束即可。它保存到build/score-reports/的CSV和JSON，区分无样本/调试/周期异常/中断。工具读取板上已经计算的平均分，串口丢帧不改变板上均值，但没有CRC的链路仍需检查。
3. 调试器只读查看`trajectory_score::latest`：yaw_ratio、pitch_ratio、yaw_mean、pitch_mean、mean_score、samples、flags。读取前先核对板上烧录版本，不能用新ELF解释旧固件RAM；串口协议本身不提供固件身份验证。

本会话后续每次烧录后的汇报口径：固件身份、幅值/周期、样本数及窗口、两轴ratio均值、0～40平均分、异常/中断标记。没有运行样本时报告“待测试”，不伪造数值。当前未设置后台监控或自动烧录。
