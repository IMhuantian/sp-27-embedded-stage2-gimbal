# Yaw转矩上限0.4试验（2026-10-23）

## 变化率16版本的只读数据

核对板上Pitch配置变化率为16.0。320组18通道RAM快照覆盖约10.401秒，均为fault=0、轨迹运行，末次本地运行均分约6.143/40。典型采样间隔约31毫秒，RAM连续读取非原子，本报告统计是调试估计。

| 指标 | Yaw | Pitch |
|---|---:|---:|
| 平均绝对误差 | 6.62° | 6.14° |
| 均方根误差 | 8.61° | 9.30° |
| 平均有符号偏差 | -0.47° | +5.48° |
| 最佳相移估计 | 滞后42毫秒 | 滞后35毫秒 |
| 输出达到±0.3 N·m比例 | 66.9% | 23.4% |

Pitch原始PI请求超限约23.1%，输出变化率受限估计约44.7%。Yaw约三分之二采样点达到转矩上限，支持先评估出力能力，而不是继续只增大变化率或位置增益。相移仅用于诊断，不修改评分时间点。Pitch平均偏差不代表可直接减去常量来修复，因为它混合动态相位、非线性及可能的重力/积分影响。

## 本轮改动

用户明确批准，仅将gimbal_task.cpp的YAW_MAX_TORQUE从0.3改0.4 N·m。该常量同时用于Yaw速度PID的输出和积分限幅，因此两者界限一同提高；PID增益Kp0.6、Ki0.2及角度P3不变。手动与轨迹模式均受影响。

Pitch转矩上限仍0.3 N·m；两轴输出变化率仍16 N·m/s；1倍680毫秒轨迹、评分公式及所有现有保护开关保持原值。没有增加前馈或改变目标/实际角零点。

这提高了Yaw允许转矩约33%，也会改变超调及结构受力。新上限下满输出反向切换理论最短50毫秒（0.8/16），并非进一步缩短指令换向时间；本试验针对饱和时的出力能力，不以该时间预测跟随改善。
