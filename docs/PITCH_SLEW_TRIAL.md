# Pitch输出变化率优化试验

对照版本：本地Git提交c64586d，标签“目标轨迹跟踪1倍版”。

运行数据表明Pitch输出频繁被变化率限制。本轮只将gimbal_task.cpp的PITCH_OUT_SLEW从3提高到8 N·m/s，保留±0.3 N·m转矩上限、PID参数、1倍幅度、680毫秒周期和所有现有保护开关状态。

该参数由Pitch双环控制器使用，因此手动、轨迹和模式接管时的Pitch出力变化都会受影响。1毫秒控制拍的最大转矩增量由0.003变为0.008 N·m，-0.3到+0.3 N·m的理论最短切换时间由200缩短为75毫秒。控制和评分任务仍为1毫秒，波形发送仍约200 Hz。

此改动是基于采样的候选优化，不能保证提分，也不能解决所有转矩饱和、重力偏置或结构耦合。已有转矩上限保持不变，5号保护保持用户此前要求的关闭状态。

验证：Debug编译；现有Pitch双环宿主测试（含限幅、变化率、抗积分饱和、模式接管、失能及非法反馈）；与c64586d比较确认控制源码只有该参数及同一行说明变化。

实机复测应与原版使用同一起始姿态、相同全幅轨迹及相同评分窗口，比较Pitch平均绝对误差、输出变化率限制比例、超调和运行均分。原版只读样本中Pitch平均绝对误差约39度、变化率受限约62%，仅为约31毫秒采样间隔的估计，不是赛事验收值。

本轮不烧录；尚未获得该参数的实机跟随与评分结果。
