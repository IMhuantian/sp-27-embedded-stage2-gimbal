## 改动与目的

- 幅值设为0.5，保留680ms正式周期和官方轨迹表。Yaw已有角度P+速度PI；Pitch继续用原位置PID、30ms超前、加速度前馈。这一切片先建立可比较的0.5基线，不同时试换算法或新增益。
- 轨迹Yaw速度上限1.5→4.5rad/s，Pitch参考变化率1.5→5.5rad/s；手动速度不变，Yaw/Pitch转矩仍0.3Nm，折叠仍1.2Nm，机械边界不放宽。提高的是参考限速，不保证实际能达到。
- 数学核查：0.5的Yaw速度峰值3.574rad/s，Pitch原速度峰值4.154rad/s，叠加超前后的导数峰值5.037rad/s。原0.15的超前参考也有约1.511rad/s，原1.5上限轻微削顶。
- 启动前检查整个离散周期的参考范围（Pitch含超前）与速度需求；完整扫描只在上电、输出尚未启动时做一次，进入轨迹时只做偏移边界比较。超界拒绝，不通过截断伪装跟踪成功。
- 0.5沿用远程的相对起点映射：Pitch从进入角向上覆盖约30°。例如进入角为“仰为正”−15°时，含超前目标约−15.887°～+15.314°，落在原±20°范围；从0°进入则被拒绝。不是自动把机构拉到−15°。应先人工核实姿态/支撑和方向，再通过现有中档低速手动定位；严禁仅按角度数字假定实际结构有余量。
- Yaw误差按±pi最短分支处理；进入轨迹就地接管Pitch目标并清两轴PID。IMU应用层发布完整角度/时间戳快照，超过25ms或非有限时停止；电机关键量按同一临界区读取。波形任务也先取完整14通道快照。
- 上档试验若故障或展开反馈不新鲜/不在展开位，停止并锁定，需要遥控有效且右拨杆回下档后才能重新尝试；不因反馈恢复自动重启。下档仍全停。零转矩不等于抗重力保持，故障时必须有机械支撑。

|---|---|---|

| 2/3 | Yaw最终速度给定/电机速度 | rad/s |
| 4 | Yaw送cmd的转矩指令 | Nm |
| 5/6 | Pitch原参考/“仰为正”实际IMU角 | rad |
| 7 | Pitch加超前、限位及变化率限制后的PID设定 | rad |
| 8 | M2006减速输出侧速度，方向尚需核对 | rad/s |

通道10：1=Yaw速度截断，2=Pitch角限位截断，4=Pitch参考变化率限制，8=任一轴PID或Pitch叠加前馈达到转矩限幅，16=任一轴输出变化率限制。它不证明CAN发送成功或实机收到相同转矩。原Pitch控制是“先夹PID再叠前馈再夹总量”，所以通道13用于观察内部需求，不能简单夹住通道13重建通道9。

通道11：0正常，1下档，2遥控失联，3Yaw反馈缺失，4Pitch反馈缺失，5姿态/跟随联锁，6轨迹范围/速度需求不允许，7折叠反馈缺失或不在展开位，8IMU未就绪/过期或关键反馈非有限。其他更高优先级当前故障可能临时遮盖已锁定原因，消失后恢复锁定码。停止时通道0/5保留最后参考，不代表仍在运动。

## 首次人工台架采集

1. 本轮没有烧录。固件已启用电机控制；未来用户烧录前右拨杆置下档并支撑机构。核实当前接线/角色：Yaw=0x206 GM6020，Pitch=0x204 M2006/36减速，折叠=0x205 GM6020。原版向近期有反馈的两条CAN发送相同指令，仍需避免重复ID。
2. 先确认中档静态保持与遥控方向，Pitch“仰为正”定位约−15°、Yaw上电编码零附近、折叠保持在展开位（±5°），核对实际机械余量；本代码不会自动对齐首姿态。
3. 人工上档开始，首次只记录短段，随时可下档全停；不要反复故障重启。若出现6，检查进入姿态/全周期范围；若7，检查折叠保持与新鲜反馈，不旁路保护。
4. 保存含进入前及首故障前后的14通道CSV。优先比较0/1、5/6，随后看7（控制器实际追的参考）、4/9/13、10、11、12。记录负载和实体轴。给定削顶、转矩长期饱和、相位滞后和反馈失效是不同问题。
5. 有数据后决定下一切片：先修时序/饱和及定位根因；若Pitch阻尼和带宽不足，再核对输出速度符号并先整定速度内环，之后接角度外环与速度前馈。加速度/重力前馈不凭空增大。本版不承诺0.5稳定；1.0仍因60°跨度超过40°软件范围而不可直接验收。
